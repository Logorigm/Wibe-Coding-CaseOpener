# Картинки кейсов

Здесь лежат картинки всех кейсов игры (`.webp` с прозрачным фоном). Путь указывается в `data/cases.js`:

```js
image: 'assets/cases/pink-capsule.webp',
```

Для своего кейса лучше всего подходит квадратная PNG/WebP с прозрачным фоном (например, 512×512).
Если картинку не указать — игра нарисует простую коробку цвета `color`.
