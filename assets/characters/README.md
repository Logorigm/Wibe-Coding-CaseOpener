# Картинки персонажей

Клади сюда картинки персонажей и указывай путь в `data/characters.js`:

```js
image: 'assets/characters/rem.png',
```

Рекомендации:
- вертикальная картинка с пропорцией **3:4** (например, 600×800 или 900×1200);
- формат PNG, JPG или WebP;
- лицо лучше держать в верхней трети — карточка обрезает картинку по центру сверху;
- имя файла — латиницей без пробелов (`rem.png`, а не `Рем 1.png`), регистр букв важен.
