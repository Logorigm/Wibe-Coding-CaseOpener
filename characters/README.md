# 📁 Персонажи картинками — самый простой способ

Для каждого персонажа выбираешь **кейс** и **редкость** — просто кладёшь картинку в нужную папку:

```
characters/
  03-neko/              ← кейс (id кейса из data/cases.js, номер = уровень)
    1-common/           ← редкость
      Мэй.png
    5-legendary/
      Рем.png           ← имя файла = имя персонажа
      Рем.txt           ← (необязательно) серия и описание
```

Имя файла становится именем персонажа (`Мэй_Татибана.png` → «Мэй Татибана»).
Цена персонажа считается **автоматически** — от цены кейса и редкости.
Как только в кейсе появляется хотя бы один твой персонаж, демо-персонажи из него исчезают.

## Папки редкостей

`1-common` (обычная) · `2-uncommon` (необычная) · `3-rare` (редкая) · `4-epic` (эпическая) · `5-legendary` (легендарная) · `6-mythic` (мифическая)

Можно называть и по-русски: `легендарная`, `редкая` и т.д.

## Файл с описанием (необязательно)

Рядом с картинкой положи текстовый файл с тем же именем, например `Рем.txt`:

```
серия: Re:Zero
описание: Горничная особняка Розвааля
цена: 5000
```

`цена` — только если хочешь задать её вручную (обычно не нужно).

## Как загрузить

**Через сайт GitHub (без программ):**
1. Открой нужную папку, например `characters/03-neko/5-legendary/`.
2. Нажми **Add file → Upload files**, перетащи картинки, нажми **Commit changes**.
3. Сборка на GitHub сама добавит персонажей в игру и соберёт новый APK
   (вкладка **Actions**, затем **Releases**).

**На компьютере:** положи картинки в папки и выполни в папке игры:

```bash
node tools/import-characters.js
```

Скрипт обновит `data/characters.auto.js` и напишет, сколько персонажей нашёл в каждом кейсе.

## Советы по картинкам

- вертикальные, пропорция **3:4** (например 600×800);
- PNG, JPG или WebP; лицо — в верхней трети (карточка обрезает картинку от центра сверху);
- один и тот же файл-имя в нескольких кейсах = один персонаж, который выпадает из нескольких кейсов
  (цена считается по первому, самому младшему кейсу).
