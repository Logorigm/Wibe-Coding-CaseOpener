# WaifuDrop — аниме кейс-симулятор

Офлайн-игра про открытие кейсов с аниме-девочками. Работает **без сервера и без установки**:
открой `index.html` в браузере — или поставь готовое **Android-приложение (APK)**. Прогресс хранится на устройстве.

> Пока ты не добавил своих персонажей, кейсы заполнены **демо-персонажами** (карточки-силуэты).
> Как только в кейсе появляется хотя бы один твой персонаж — демо из этого кейса исчезают.

---

## Как играть

Новичок видит только **кейсы**: открыл — получил персонажа — продал или оставил. Остальное открывается постепенно, с уровнем:

| Уровень | Что открывается |
|---|---|
| 1 | Кейсы, инвентарь, бесплатный подарок раз в час |
| 2 | Открытие нескольких кейсов за раз, коллекция |
| 3 | Профиль и достижения |
| 4 | Апгрейдер |
| 5 | Краш |
| 6 | Коинфлип |
| 7 | Рулетка |
| 8 | Джекпот |

- **Кейсы.** На каждом уровне (с 1 по 15) открываются **3–4 новых кейса**. Чем выше уровень, тем дороже кейсы и тем выше их
  средний возврат (с 80% до 94%), поэтому выгодно переходить к новым. Внутри уровня кейсы отличаются разбросом:
  в «низком» чаще средние персонажи, в «высоком» и «элитном» — больше шанс на легендарных и мифических.
- **Опыт** дают монеты, потраченные на кейсы, и ставки в играх. На уровень нужно 10–30 открытий «среднего» кейса уровня.
  За новый уровень — монеты.
- **Коллекция** — все персонажи, которых ты хоть раз выбивал. За полный набор кейса и за 10/25/50/75/100% всей коллекции
  монеты начисляются сразу.
- **Достижения** имеют редкость (от обычных до мифических) — чем реже, тем больше награда.
- Валюта одна — **монеты**. Если они закончились, на экране кейсов появится кнопка помощи.

## Готовый APK

APK собирается **автоматически на GitHub** после каждой отправки изменений (`.github/workflows/android.yml`).

**Где скачать:** страница репозитория → **Releases** → последний релиз → файл `WaifuDrop-1.0.N.apk`
(или `https://github.com/<владелец>/<репозиторий>/releases/latest`). Ещё он лежит во вкладке **Actions** → сборка → **Artifacts**.

**Установка:** скачай APK на телефон и открой. Если Android спросит — разреши установку из этого источника.
Новая версия ставится поверх старой, прогресс сохраняется. Нужен Android 8.0 или новее.

<details>
<summary>Как это устроено</summary>

- `android/` — маленькое Android-приложение: окно WebView, в котором работает та же игра. При сборке файлы игры
  (`index.html`, `css/`, `js/`, `data/`, `assets/`, `characters/`) копируются внутрь APK.
- Сборка на GitHub: импорт персонажей из папок → сборка Gradle → подпись → публикация в Releases.
- APK подписан ключом `android/app/waifudrop.keystore` (пароль `waifudrop`), чтобы обновления ставились поверх.
  Для Google Play сделай свой ключ и передай его через переменные `WAIFUDROP_KEYSTORE`, `WAIFUDROP_STORE_PASSWORD`,
  `WAIFUDROP_KEY_ALIAS`, `WAIFUDROP_KEY_PASSWORD`.
- Собрать самому: открой `android/` в Android Studio или выполни `./gradlew assembleRelease` в папке `android/`.

</details>

## Как добавить персонажей (выбирая кейс и редкость)

Цену персонажа считать не нужно — игра подбирает её сама от цены кейса и редкости.

### Способ 1 — картинками по папкам (проще всего)

```
characters/<номер-кейс>/<редкость>/<Имя>.png
например: characters/02-pink-capsule/5-legendary/Рем.png
```

Папки для всех 53 кейсов и 6 редкостей уже созданы. Через сайт GitHub: открой нужную папку → **Add file → Upload files** →
перетащи картинки → **Commit changes**. Сборка сама добавит персонажей в игру и выпустит новый APK.
На компьютере: положи картинки и выполни `node tools/import-characters.js`.
Список кейсов, уровней и папок — в [`characters/README.md`](characters/README.md).

### Способ 2 — Конструктор в игре

**Настройки → Режим разработчика** → в меню появится **Конструктор** → вкладка «Персонаж»: заполни форму,
скопируй готовый код и вставь в `data/characters.js`.

### Способ 3 — вручную в `data/characters.js`

```js
{ id: 'rem', name: 'Рем', rarity: 'legendary', cases: ['pink-capsule'], image: 'assets/characters/rem.png', series: 'Re:Zero' },
```

Картинки персонажей лучше вертикальные **3:4** (например 600×800).

## Что можно настроить

Всё в папке `data/`:

| Файл | Что там |
|---|---|
| `config.js` | Стартовые монеты, редкости, экономика, уровни и награды, **какие разделы открываются на каком уровне**, награды коллекции, мини-игры |
| `cases.js` | Кейсы: уровень, цена, окупаемость `rtp`, картинка, шансы редкостей |
| `characters.js` | Твои персонажи (вручную) |
| `characters.auto.js` | Персонажи из папки `characters/` — создаётся автоматически, руками не правь |
| `demo.js` | Демо-персонажи (`enabled: false` — выключить) |
| `achievements.js` | Достижения: редкость, условие, награда |

Картинки кейсов — в `assets/cases/`, монета — `assets/ui/coin-*.webp`.

## Запуск в браузере

- Открой `index.html` двойным кликом,
- или запусти сервер в папке игры: `npx serve .` / `python -m http.server 8000`,
- или включи **GitHub Pages** (Settings → Pages → ветка, папка `/ (root)`).

Сохранение: **Настройки → Сохранение** — скачать/загрузить файл или скопировать/вставить код.

## Структура

```
index.html            — страница игры
data/                 — данные: кейсы, персонажи, настройки, достижения
characters/           — картинки персонажей по папкам «кейс/редкость»
tools/                — импорт персонажей из папок
assets/               — картинки кейсов, монета, шрифт
css/                  — стили (base, components и по разделам)
js/core/              — ядро: данные и цены, сохранения, звук, окна, роутер
js/systems/           — экономика, инвентарь и коллекция, достижения, кейсы
js/pages/             — разделы (кейсы, инвентарь, коллекция, профиль, игры, настройки, конструктор)
js/games/             — мини-игры
android/              — Android-приложение для сборки APK
.github/workflows/    — автоматическая сборка APK
```
