# 🌸 WaifuDrop — аниме кейс-симулятор

Игра-симулятор открытия кейсов с аниме-девочками. Работает **без сервера и без установки**:
открой `index.html` в браузере — или поставь готовое **Android-приложение (APK)**. Прогресс сохраняется на устройстве.

> Пока ты не добавил своих персонажей, кейсы заполнены **демо-персонажами** с нарисованными портретами.
> Как только в кейсе появляется хотя бы один твой персонаж — демо из этого кейса исчезают.

---

## 📱 Готовый APK

APK собирается **автоматически на GitHub** после каждой отправки изменений (workflow `.github/workflows/android.yml`).

**Где скачать:** страница репозитория → справа **Releases** → последний релиз → файл `WaifuDrop-1.0.N.apk`.
Прямая ссылка на последний релиз: `https://github.com/<владелец>/<репозиторий>/releases/latest`.

Ещё APK лежит во вкладке **Actions** → последняя сборка «Android APK» → блок **Artifacts** (скачивается zip-архивом).

**Установка:** скачай APK на телефон и открой. Если Android спросит — разреши установку из этого источника.
Новая версия ставится поверх старой, прогресс сохраняется. Нужен Android 8.0 или новее.

<details>
<summary>Как это устроено (для любопытных)</summary>

- `android/` — маленькое Android-приложение: окно WebView, в котором работает та же игра, что и в браузере.
  При сборке файлы игры (`index.html`, `css/`, `js/`, `data/`, `assets/`, `characters/`) копируются внутрь APK.
- Сборка на GitHub: импорт персонажей из папок → сборка Gradle → подпись → публикация в Releases.
  Номер версии = номер сборки (`1.0.1`, `1.0.2`, …).
- APK подписан ключом `android/app/waifudrop.keystore` (пароль `waifudrop`), чтобы обновления ставились поверх.
  Для публикации в Google Play сделай свой ключ и передай его через секреты/переменные
  `WAIFUDROP_KEYSTORE`, `WAIFUDROP_STORE_PASSWORD`, `WAIFUDROP_KEY_ALIAS`, `WAIFUDROP_KEY_PASSWORD`.
- Собрать самому: открой папку `android/` в Android Studio, или выполни `./gradlew assembleRelease` в папке `android/`
  (нужны JDK 17 и Android SDK). Готовый файл: `android/app/build/outputs/apk/release/app-release.apk`.
- Экспорт сохранения в приложении открывает системное окно «Сохранить как», импорт — выбор файла.

</details>

## 🪜 Как устроена прокачка

- **Опыт** дают открытия кейсов (0.25 опыта за монету) и ставки в мини-играх.
  Чтобы взять уровень, нужно примерно **10 открытий самого крупного доступного кейса** — темп всегда одинаковый.
- **Каждый уровень с 2 по 20 открывает новый кейс.** Чем выше кейс, тем больше его **отдача** (средний дроп ÷ цена):
  на 1 уровне это 80%, на 20 — 99%. Поэтому игроку выгодно всё время переходить на самый крупный кейс.
- Старые кейсы не бесполезны: **у каждого кейса свои персонажи**, а за полную коллекцию кейса дают награду
  (монеты ×10 от цены кейса + кристаллы). Коллекцию считают по всем, кого ты хоть раз выбивал.
- Награда за уровень — 3 цены лучшего доступного кейса; каждые 5 уровней — кристаллы, каждые 10 — билет в «Божественный кейс».
  Монеты в заданиях, ежедневных наградах и колесе удачи тоже растут вместе с уровнем.

## 👧 Как добавить персонажей в кейсы (выбирая кейс и редкость)

Для каждого персонажа ты выбираешь **кейс** и **редкость**. **Цену считать не нужно** — игра сама подбирает цены так,
чтобы у кейса была его отдача (`rtp`). Есть три способа — выбирай любой.

### Способ 1 — картинками по папкам (проще всего, работает с телефона)

В репозитории уже есть папки для всех кейсов и редкостей:

```
characters/
  03-neko/                 ← кейс (номер = уровень, дальше id кейса)
    1-common/              ← редкость
      Мэй.png              ← имя файла = имя персонажа
    5-legendary/
      Рем.png
      Рем.txt              ← (необязательно) серия и описание
```

Редкости: `1-common` (обычная) · `2-uncommon` (необычная) · `3-rare` (редкая) · `4-epic` (эпическая) ·
`5-legendary` (легендарная) · `6-mythic` (мифическая).

**Через сайт GitHub, без программ:**
1. Открой нужную папку, например `characters/03-neko/5-legendary/`.
2. Нажми **Add file → Upload files**, перетащи картинки и нажми **Commit changes**.
3. Сборка на GitHub сама добавит персонажей в игру (обновит `data/characters.auto.js`) и выпустит новый APK в **Releases**.

**На компьютере:** положи картинки в папки и выполни в папке игры `node tools/import-characters.js` — скрипт обновит
`data/characters.auto.js` и покажет, сколько персонажей нашёл в каждом кейсе.

Файл `Рем.txt` рядом с картинкой (необязательно):

```
серия: Re:Zero
описание: Горничная особняка Розвааля
цена: 5000
```

`цена` — только если хочешь задать её вручную. Одинаковое имя файла в папках разных кейсов = один персонаж,
который выпадает из нескольких кейсов. Подробнее — в `characters/README.md`.

### Способ 2 — через Конструктор в игре

1. **⚙️ Настройки** → включи **«Режим разработчика»** → в меню появится **🛠️ Конструктор**.
2. Вкладка **«Персонаж»**: имя, редкость, картинка, галочки нужных кейсов. Справа — карточка, цена,
   которую персонаж получит в этом кейсе, и **готовый код**.
3. **«📋 Копировать»** → вставь код в `data/characters.js` внутрь `GAME_DATA.characters = [ ... ]`.
   Кнопка **«▶️ Добавить в игру для теста»** добавляет персонажа сразу, без правки файлов (до перезагрузки).

### Способ 3 — вручную в `data/characters.js`

Картинку положи, например, в `assets/characters/` (лучше вертикальную **3:4**, например 600×800, PNG/JPG/WebP), и добавь:

```js
{
  id: 'rem',                           // уникальный id латиницей
  name: 'Рем',
  rarity: 'legendary',                 // common | uncommon | rare | epic | legendary | mythic (или по-русски)
  cases: ['neko'],                     // в какие кейсы положить (id из таблицы выше)
  image: 'assets/characters/rem.png',
  series: 'Re:Zero',                   // необязательно
  description: 'Горничная особняка Розвааля.', // необязательно
},
```

Необязательно: `value` — своя цена вместо автоматической.

> Если картинка не найдётся — игра не сломается: подставит нарисованный портрет.
> Проверить всё разом: **Конструктор → Проверка данных** (там же цены, шансы и фактическая отдача каждого кейса).

## 🎁 Как добавить или изменить кейс

Кейсы — в `data/cases.js`. Пример нового кейса:

```js
{
  id: 'rezero',                  // уникальный id (его же пишешь в cases у персонажа и в имени папки)
  name: 'Кейс Re:Zero',
  description: 'Возвращение смертью в комплекте',
  requiredLevel: 7,              // с какого уровня открывается
  price: 400,                    // цена (0 = бесплатно, 'auto' = посчитать по среднему дропу)
  currency: 'coins',             // 'coins' — монеты, 'gems' — кристаллы
  rtp: 0.9,                      // отдача: в среднем игрок получает 90% цены кейса
  color: '#60a5fa',
  emblem: 'heart',               // значок нарисованной коробки: star|heart|moon|paw|flower|crown|gem|fire
  image: 'assets/cases/rezero.png', // своя картинка кейса (необязательно)
  items: [],                     // можно не заполнять — хватит cases: ['rezero'] у персонажей или папки characters/NN-rezero/
  rarityWeights: { common: 45, uncommon: 30, rare: 16, epic: 7, legendary: 2, mythic: 0.3 }, // шансы редкостей
  pity: { count: 30, rarity: 'legendary' },  // гарант (необязательно)
},
```

В `items` можно писать: `'rem'` (персонаж), `{ id: 'rem', weight: 0.5 }` (со своим шансом), `'rarity:epic'`,
`'series:Re:Zero'`, `'case:neko'` (все персонажи другого кейса), `'*'` (вообще все).

Шанс редкости (`rarityWeights`) делится поровну между её персонажами в кейсе. Ещё есть `cooldown` (бесплатный кейс раз в N минут),
`availableFrom` / `availableUntil` (ивент на время), `badge`, `hidden`, `collectionReward`.

## 🎮 Мини-игры

Список и порядок мини-игр — в `data/config.js` → `games.enabled`:

```js
enabled: ['crash', 'roulette', 'coinflip', 'jackpot', 'upgrade'],
```

В игре есть ещё `mines` (мины), `dice` (кости), `memory` (мемори) и `wheel` (колесо удачи на ставку) — допиши их id, чтобы включить.
Бесплатное колесо удачи раз в день работает всегда.

Там же настраиваются выплаты: `coinflip.payout`, сектора рулетки (`roulette.sectors`: цвет, множитель, сколько ячеек),
символы и копилка джекпота (`jackpot.seed`, `jackpot.contribution` — доля ставки в копилку, `jackpot.fullBet` — ставка,
с которой забираешь копилку целиком), `crash.houseEdge` и т.д. В правилах каждой игры (кнопка «❔ Правила») видны шансы.

Новая мини-игра — один файл в `js/games/` с `App.games.register({ id, name, icon, render(ctx, host) { … } })`
и подключение в `index.html`.

## ⚙️ Что ещё можно настроить

Всё в папке `data/`:

| Файл | Что там |
|---|---|
| `config.js` | Стартовый баланс, **редкости** (названия, цвета, шансы, `valueMult`), экономика, шайни, уровни и награды, титулы, награды коллекции, ежедневные награды, мини-игры, магазин, рамки, имена ботов |
| `cases.js` | Кейсы |
| `characters.js` | Твои персонажи (вручную) |
| `characters.auto.js` | Персонажи из папки `characters/` — создаётся автоматически, руками не правь |
| `demo.js` | Демо-персонажи (`enabled: false` — выключить совсем) |
| `achievements.js` | Достижения (`stat` + `goal` + `reward`) |
| `quests.js` | Пул ежедневных заданий |
| `promocodes.js` | Промокоды |

Награда (`reward`) везде записывается одинаково:

```js
{ coins: 500, gems: 10, dust: 100, xp: 200, tickets: { neko: 3 }, characters: ['rem', { id: 'ram', shiny: true }] }
```

## 🚀 Как запустить в браузере

- Открой `index.html` двойным кликом.
- Или запусти локальный сервер в папке игры: `npx serve .` или `python -m http.server 8000`.
- Или выложи на **GitHub Pages**: Settings → Pages → Branch → папка `/ (root)` → Save.

## 💾 Сохранения

- Прогресс хранится на устройстве (`localStorage` браузера или приложения).
- **Настройки → Сохранение**: скачать/загрузить файл, скопировать/вставить код — так можно перенести прогресс между устройствами.
- Если поменять `saveKey` в `config.js`, у всех начнётся новый прогресс.

## ⌨️ Горячие клавиши

- **Пробел** — открыть кейс ещё раз / сыграть в мини-игру
- **S** — пропустить анимацию рулетки
- **Esc** — закрыть окно
