# 🌸 WaifuDrop — аниме кейс-симулятор

Браузерная игра-симулятор открытия кейсов с аниме-девочками. Работает **без сервера и без установки**:
скачай папку и открой `index.html` в браузере. Прогресс сохраняется в браузере.

> Сейчас в игре 32 **демо-персонажа** с автоматически нарисованными портретами.
> Замени их на своих — ниже подробно написано, как.

## ✨ Что есть в игре

| Раздел | Что внутри |
|---|---|
| 🎁 **Кейсы** | Рулетка как в CS, открытие ×1/×2/×3/×5/×10, бесплатный кейс по таймеру, билеты, **гарант** (pity), шансы каждого персонажа на странице кейса |
| ✨ **Редкости** | 6 редкостей (от «Обычной» до «Мифической» с радужной рамкой) + **шайни**-версии с голографическим эффектом |
| 🎒 **Инвентарь** | Поиск, фильтры, сортировка, «стопки», массовая продажа/распыление, продажа дубликатов, закрепление 🔒 |
| 📖 **Коллекция** | Все персонажи (неоткрытые — размытым силуэтом), прогресс по каждому кейсу, награды за полную коллекцию, **крафт** из звёздной пыли |
| ⚔️ **Батлы** | Открывай кейсы против 1–3 ботов, победитель забирает всё. Есть «безумный режим» |
| 🆙 **Апгрейд** | Ставишь персонажей и монеты ради более дорогого персонажа, шанс на круговой шкале |
| 📜 **Контракты** | 5 персонажей одной редкости → 1 следующей редкости (новые для тебя выпадают чаще) |
| 🎮 **Мини-игры** | Ракета (краш), Мины, Колесо удачи (+бесплатный спин в день), Слоты, Монетка, Кости, Мемори |
| 🏆 **Задания** | Ежедневная награда (серия 7 дней), 3 задания в день + бонус, 40+ достижений |
| 🛒 **Магазин** | Промокоды, обмен монет на кристаллы, бусты (×2 опыт, удача), билеты, рамки аватара |
| 👤 **Профиль** | Аватар, рамка, титул, статус, витрина из 6 персонажей, статистика, история открытий |
| ⭐ **Уровни** | Опыт за всё, награды за каждый уровень, титулы, некоторые разделы и кейсы открываются с уровнем |
| ⚙️ **Настройки** | Звук и громкость, скорость анимаций, эффекты, 6 цветовых тем, экспорт/импорт сохранения, сброс |
| 🛠️ **Конструктор** | Добавление персонажей и кейсов с предпросмотром и готовым кодом, проверка данных, окупаемость кейсов, читы и симуляция |

Плюс: живая лента дропов, звуки (генерируются в браузере), конфетти, падающие лепестки сакуры, адаптив под телефон.

## 🚀 Как запустить

**Вариант 1 (проще всего):** открой файл `index.html` двойным кликом.

**Вариант 2 (локальный сервер):** если браузер что-то блокирует, запусти в папке игры:

```bash
npx serve .
# или
python -m http.server 8000
```

и открой показанный адрес (например, `http://localhost:8000`).

**Вариант 3 (в интернет через GitHub Pages):** Settings → Pages → Branch: выбери ветку и папку `/ (root)` → Save.
Через минуту игра будет доступна по ссылке вида `https://<ник>.github.io/<репозиторий>/`.

## 👧 Как добавить персонажа

### Способ 1 — через Конструктор (удобнее всего)

1. В игре открой **⚙️ Настройки** → включи **«Режим разработчика»**.
2. В меню появится **🛠️ Конструктор** → вкладка **«Персонаж»**.
3. Заполни имя, редкость, путь к картинке, отметь кейсы — справа сразу видно карточку и **готовый код**.
4. Нажми **«📋 Копировать»** и вставь код в файл `data/characters.js` (внутрь массива `GAME_DATA.characters = [ ... ]`).
5. Обнови страницу — персонаж в игре.

Кнопка **«▶️ Добавить в игру для теста»** сразу добавляет персонажа без правки файлов (до перезагрузки страницы).

### Способ 2 — вручную

1. Положи картинку в папку `assets/characters/` (лучше вертикальную **3:4**, например 600×800, PNG/JPG/WebP).
2. Открой `data/characters.js` и добавь объект в массив:

```js
{
  id: 'rem',                           // уникальный id латиницей, без пробелов
  name: 'Рем',                         // имя
  rarity: 'legendary',                 // common | uncommon | rare | epic | legendary | mythic
  image: 'assets/characters/rem.png',  // путь к картинке
  series: 'Re:Zero',                   // тайтл (необязательно)
  description: 'Горничная особняка Розвааля.', // описание (необязательно)
  cases: ['sakura', 'neko'],           // в какие кейсы добавить (необязательно)
},
```

Необязательные поля: `value` (своя цена продажи вместо стандартной по редкости), `dust`, `craft`.

> Если картинка не найдётся — игра не сломается: подставит нарисованный портрет и напишет в консоль, какой файл не найден.
> Проверить все картинки разом: **Конструктор → Проверка данных → 🖼️ Проверить картинки**.

## 🎁 Как добавить кейс или положить персонажа в кейс

Положить персонажа в кейс можно **двумя способами** (работают оба, можно комбинировать):

- у персонажа указать `cases: ['id_кейса']`
- или у кейса вписать id персонажа в `items`

Пример кейса в `data/cases.js`:

```js
{
  id: 'rezero',                  // уникальный id
  name: 'Кейс Re:Zero',
  description: 'Возвращение смертью в комплекте',
  price: 300,                    // цена (0 = бесплатно)
  currency: 'coins',             // 'coins' — монеты, 'gems' — кристаллы
  color: '#60a5fa',              // цвет кейса
  image: 'assets/cases/rezero.png', // картинка кейса (необязательно — иначе нарисуется коробка)
  emblem: 'heart',               // значок на нарисованной коробке: star|heart|moon|paw|flower|crown|gem|fire
  category: 'theme',             // free | standard | theme | event | premium
  badge: 'NEW',                  // наклейка (необязательно)
  requiredLevel: 3,              // с какого уровня доступен (необязательно)
  items: ['rem', 'ram', 'emilia', 'rarity:common'],
  rarityWeights: { common: 50, uncommon: 28, rare: 14, epic: 6, legendary: 2 }, // необязательно
  pity: { count: 30, rarity: 'legendary' },  // гарант (необязательно)
  collectionReward: { gems: 20 },            // награда за сбор всех персонажей кейса
},
```

В `items` можно писать:

| Запись | Что значит |
|---|---|
| `'rem'` | конкретный персонаж |
| `{ id: 'rem', weight: 0.5 }` | персонаж со своим шансом |
| `'rarity:epic'` | все персонажи этой редкости |
| `'series:Re:Zero'` | все персонажи этой серии |
| `'*'` | вообще все персонажи |

**Как считаются шансы:** у каждой редкости есть вес (по умолчанию из `config.js`, можно переопределить в `rarityWeights` кейса).
Шанс редкости делится поровну между её персонажами в кейсе. Итоговые проценты видны на странице кейса.

**Бесплатный кейс по таймеру:** `price: 0, cooldown: 60` — открывается раз в 60 минут.

**Ивент на время:** `availableUntil: '2026-12-31'` (и/или `availableFrom`).

> 💡 **Баланс.** В **Конструктор → Проверка данных** есть таблица с «средним дропом» и **RTP** каждого кейса
> (сколько процентов цены в среднем возвращается игроку). Обычно ставят 85–97%. Больше 100% — кейс можно бесконечно
> фармить. Все демо-кейсы настроены на ~91–94%. Там же — **симуляция** 10 000 открытий для проверки шансов.

## 🧹 Как убрать демо-персонажей

1. Удали (или замени) объекты в `data/characters.js`.
2. Поправь `items` в `data/cases.js` — убери id удалённых персонажей (или удали/замени демо-кейсы).
3. Обнови страницу. Если что-то забыл — игра покажет предупреждение, а список проблем будет в **Конструктор → Проверка данных**.

Также демо-кейсы упоминаются в наградах: `dailyRewards`, `levels.reward`, `shop.tickets` в `data/config.js`
и в `data/promocodes.js` (кейсы `sakura`, `neko`, `divine`). Если удалишь эти кейсы — поменяй там id на свои.

## ⚙️ Что ещё можно настроить

Всё в папке `data/`:

| Файл | Что там |
|---|---|
| `config.js` | Название игры, стартовый баланс, **редкости** (названия, цвета, шансы, цены), шайни, уровни и награды за них, титулы, ежедневные награды, мини-игры (шансы и выплаты), магазин, рамки, имена ботов |
| `characters.js` | Персонажи |
| `cases.js` | Кейсы |
| `achievements.js` | Достижения (`stat` + `goal` + `reward`) |
| `quests.js` | Пул ежедневных заданий |
| `promocodes.js` | Промокоды |

Награда (`reward`) везде записывается одинаково:

```js
{ coins: 500, gems: 10, dust: 100, xp: 200, tickets: { sakura: 3 }, characters: ['rem', { id: 'ram', shiny: true }] }
```

## 💾 Сохранения

- Прогресс хранится в `localStorage` браузера (отдельно для каждого браузера/устройства).
- **Настройки → Сохранение**: скачать файл / загрузить файл / скопировать код / вставить код — так можно перенести прогресс.
- Если поменять `saveKey` в `config.js`, у всех начнётся новый прогресс.

## 🗂️ Структура проекта

```
index.html            — страница игры (подключает все файлы)
data/                 — ✏️ ДАННЫЕ ИГРЫ (редактируй их)
assets/characters/    — картинки персонажей
assets/cases/         — картинки кейсов
css/                  — стили (base, cards, pages, games)
js/core/              — ядро: утилиты, сохранения, данные, звук, эффекты, интерфейс, роутер
js/art/               — генератор портретов-заглушек и коробок кейсов
js/components/        — рулетка, поле ставки, выбор персонажей
js/systems/           — экономика, инвентарь, задания/достижения, кейсы, лента дропов
js/pages/             — страницы (главная, кейсы, инвентарь, батлы, апгрейд, конструктор…)
js/games/             — мини-игры
```

Новая мини-игра добавляется одним файлом в `js/games/` через `App.games.register({ id, name, icon, render(ctx, host) { … } })`
и подключением его в `index.html` — посмотри любую существующую игру как пример.
